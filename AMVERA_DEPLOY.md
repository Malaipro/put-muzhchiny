# Запуск «Пути Мужчины» на Amvera

Эта памятка — для одного законченного запуска. Сначала проверяем Amvera, затем подключаем готовый адрес в Telegram.

## Что уже готово в проекте

- сборка приложения в Docker;
- запуск на порту `80`;
- корректное открытие внутренних экранов по прямым ссылкам;
- адрес проверки `/healthz`, который должен отвечать `ok`;
- подключение к Telegram Mini Apps.

## Что указать в Amvera

1. Источник: GitHub-репозиторий `Malaipro/put-muzhchiny`.
2. Ветка: та, в которой опубликована проверенная версия. Для постоянного запуска — `main`.
3. Тип сборки: Docker.
4. Корень проекта: `/`.
5. Порт: `80`.

Переменные окружения для текущего пробного запуска не нужны. Токен Telegram-бота сюда не добавлять.

## Проверка после сборки

1. В журнале Amvera есть финальная строка об успешном запуске.
2. `https://<адрес-amvera>/healthz` показывает `ok`.
3. Главная страница открывается без `Internal Error`.
4. На телефоне проходятся: онбординг, бросок, клетка и принятие задания.
5. Только после этого HTTPS-адрес передаётся в BotFather.
