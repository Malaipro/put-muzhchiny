# Запуск «Пути Мужчины» на Amvera

Эта памятка — для одного законченного запуска. Сначала проверяем Amvera, затем подключаем готовый адрес в Telegram.

## Что уже готово в проекте

- сборка приложения в Docker;
- запуск на порту `80`;
- корректное открытие внутренних экранов по прямым ссылкам;
- адрес проверки `/healthz`, который должен отвечать `{"ok":true,...}`;
- подключение к Telegram Mini Apps.
- серверная очередь Telegram-напоминаний в постоянном каталоге `/data`.

## Что указать в Amvera

1. Источник: GitHub-репозиторий `Malaipro/put-muzhchiny`.
2. Ветка: та, в которой опубликована проверенная версия. Для постоянного запуска — `main`.
3. Тип сборки: Docker.
4. Корень проекта: `/`.
5. Порт: `80`.

Для отправки напоминаний нужна секретная переменная `TELEGRAM_BOT_TOKEN`. Её добавляют только в разделе `Переменные` Amvera, не в код и не в чат. Необязательная переменная `PUBLIC_APP_URL` задаёт HTTPS-адрес кнопки возврата в игру. Подробности — в [BOT_SETUP.md](./BOT_SETUP.md).

## Проверка после сборки

1. В журнале Amvera есть финальная строка об успешном запуске.
2. `https://<адрес-amvera>/healthz` показывает `"ok":true` и `"remindersConfigured":true`.
3. Главная страница открывается без `Internal Error`.
4. На телефоне проходятся: онбординг, бросок, клетка и принятие задания.
5. После принятия действия на клетке сразу приходит подтверждение от бота.
6. Только после этого HTTPS-адрес передаётся в BotFather.

Перед каждым релизом адрес `https://put-muzhchiny-galdyan.mia0.amvera.tech/` и точный публичный интерфейс нужно проверить заново: успешная сборка сама по себе не доказывает, что запущен новый контейнер.
